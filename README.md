Interactive Resume Generator — users fill a simple form (name, skills, education, experience, photo) and a beautifully formatted resume is generated instantly. Pure frontend project using HTML, CSS &amp; JavaScript

# Modern Resume Generator

A fast and easy-to-use web application that generates a professional 
resume directly in the browser. No sign-up, no backend — just fill the 
form and get your resume!

## ✨ Features
- 📸 Profile photo upload
- 📝 Fill form → instant resume preview
- 🎨 Clean & modern UI
- ⚡ Pure frontend — HTML, CSS, JavaScript
- 📱 Responsive design

1. Open `index.html` in browser

3. Click "Generate Resume"
